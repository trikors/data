# data
Data PHP program for accessing MySQL database
Приложение data.php

работает с базой данный MySQL. Запускаете приложение по командой строке,
php data.php. Информация дла логина в базу данных находится в совместном файле
login.php.
$hn, или име хоста
$un, это имя пользователя
$pw, пароль
$db, название базы данных, к которой предоствляется доступ.

После обновления этой информации запускаете само приложение.
В начале, оно проверит наличие таблицы (условно) myTable, если этой таблицы
нет, то тогда создаете её командой CREATE.

После этого, приложение предоставляет вам
следующий выбор:

POST , для ввода информации по схеме (title, description, status)
GET, для вывода всей информации на экран
GETID, для вывода только одной строки на экран. После ввода GETID вводите ID необходимой строки
PUT, для изменения строки под необходимиым ID
DELETE, для удаления строки под вводимым Вами ID
QUIT, для выхода из приложения.

ВАЖНО при вводе данных, избегайте использование кавычек, так как это может привести к ошибкам
MySQL.
